​<table>
<tr>
<td valign="top" width="50%">
<h4><code>SEC</code> Frontend, Mobile & API Security</h4>
<ul>
<li><strong>Client & Mobile Vaults:</strong> Strict CSP headers, XSS/CSRF guards, <code>HttpOnly / SameSite=Strict</code> cookie sessions, hardware-backed storage (<strong>iOS Keychain, Android Keystore, Expo SecureStore</strong>), and SSL/TLS certificate pinning.</li>
<li><strong>Zero-Trust API Defense:</strong> Short-lived asymmetric JWTs (<strong>RS256/ES256</strong>) with refresh rotation, granular <strong>RBAC/ABAC & BOLA/IDOR</strong> checks, parameterized SQL, sliding-window rate limiting, <strong>HMAC webhook verification</strong>, and immutable audit trails.</li>

<li><strong>Edge & Offline Sync:</strong> HTTP & CDN edge caching (<code>Cache-Control</code>, <code>stale-while-revalidate</code>, tag-based invalidation) paired with offline-first <strong>SQLite</strong> persistence on mobile clients.</li>
